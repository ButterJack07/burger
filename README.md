# 🍔 小岛汉堡社 · Burger Island

竖屏小摊经营小游戏：上方挂小票订单，下方使用配料盒、制作台、煎台与薯条炸锅。没有后端，没有构建依赖，食物和人物都是本地 SVG 绘制。

## 开始游戏

**直接双击 `index.html`**，使用 Chrome、Edge、Safari 或 Firefox 打开即可。无需安装依赖或启动服务器，也不请求外部字体、图片或音频。

手机推荐通过 GitHub Pages 地址打开，**竖屏游玩**。桌面以手机大小的摊位展示。

### GitHub Pages 部署

将本目录的文件上传到 `ButterJack07/burger` 仓库根目录，在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，选择代码所在分支及 **/(root)** 并保存。发布后通常可访问：

`https://butterjack07.github.io/burger/`

该链接只有完成上传和 Pages 发布后才生效。

## 玩法

1. 阅读订单：明确配方会显示食材标签；口味谜语通过比喻提示配料，可免费查看提示。
2. 按住配料拖入盘子叠汉堡；牛肉、鸡排、培根、毛豆肉饼和奶蛙肉饼需要**先拖到煎台煎约 5 秒，再从煎台拖到汉堡上**。点击配料/煎好的肉饼也可辅助操作；点击已叠的一层可移除。
3. 盖上面包，点击出餐。满意度至少 70 为好评，高满意度会得到小费。
4. 食材在出餐时结算；修改配料不会扣金币。收入减去成本即本单净收益。
5. 在商店永久解锁食材，升级等餐时间、小费和最大叠层数。
6. 第 2 天起有汉堡薯条套餐：点击炸锅，6 秒后再点一下装盘。漏掉薯条扣 35 分；装盘薯条成本 3 金币，套餐增加 12 金币基础售价。

### 三种模式

- **小岛故事**：8 天关卡，达到每日好评目标即可通关。根据平均满意度获得 1–3 星；首次通关全额奖励，重玩通关获得 35% 奖励。
- **不打烊的小店**：从 3 点口碑开始，客人逐渐变得更急。超时或低于 70 分损失 1 点口碑，口碑耗尽结算。最高服务纪录会保存。
- **创意厨房**：无计时、无食材费用，自由制作并命名收藏。使用已解锁食材，最多保存 30 份作品。

18 种配料包括奶油、草莓酱、菠萝、森林蘑菇、辣椒、冰淇淋，以及两种抽象的可煎制肉饼：豆荚耳朵的毛豆肉饼、奶白蛙蛙造型的奶蛙肉饼。订单只会使用已经解锁的配料。

打开弹窗或将页面切到后台会暂停订单计时。音效默认关闭，点击右上角音符开启。

## 存档

金币、升级、配料、关卡、星星和收藏保存在当前浏览器的 `localStorage`。正在制作的订单不保存，刷新会重新开始当前已解锁关卡。清除浏览器数据会删除存档；直接打开文件与 Pages 网站之间不共享存档。无法使用本地存储的浏览器仍可玩，但进度不会持久保存。

## 文件

- `index.html`：游戏页面。
- `style.css`：响应式布局和基础样式。
- `cartoon.css`：卡通游戏皮肤。
- `landscape.css`：横屏三栏工作台、煎台和拖拽反馈。
- `stall.css`：当前竖屏摊位布局、小票订单架、配料盒与炸锅样式。
- `game.js`：游戏系统、SVG 插画、存档和合成音效。
- `favicon.svg`：图标。
- `tests/game.test.cjs`：订单评分和核心经营流程检查，执行 `node --test tests/game.test.cjs`。

项目使用原生 HTML、CSS、JavaScript，不需要 npm install。
